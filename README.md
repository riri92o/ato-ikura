# あといくら

スマートフォンで使える、利用額と実際の出金額を分けて管理する支出管理アプリです。データは利用中のブラウザ内に保存されます。

## 1. VS Codeで起動する

1. VS Codeでこのフォルダを開きます。
2. 左側の拡張機能から「Live Server」をインストールします。
3. `index.html`を開きます。
4. 画面右下の「Go Live」を押します。
5. ブラウザに「あといくら」が表示されたら完了です。

`index.html`を直接ダブルクリックしても基本機能は使えますが、PWAやオフライン機能の確認にはLive Serverまたは公開URLが必要です。

## 2. 最初に行う設定

1. 下部の「カード」から、使っているクレジットカードを登録します。
2. 下部の「設定」で、必要なら現在残高と最低限残したい金額を入力します。
3. 右下の「＋」から支出を登録します。
4. 動作を試したい場合は「設定」→「サンプルデータを追加」を押します。サンプルだけ後から削除できます。

## 3. GitHub Pagesへ公開する最短手順

1. GitHubで新しいリポジトリを作ります。公開範囲は、GitHub Pagesを無料で使う場合は「Public」を選びます。
2. VS Code上部の「ターミナル」→「新しいターミナル」を開きます。
3. 次を上から1行ずつ実行します。`あなたのURL`だけ、作成したリポジトリ画面に表示されるURLへ置き換えます。

```bash
git init
git add .
git commit -m "Create Ato Ikura app"
git branch -M main
git remote add origin あなたのURL
git push -u origin main
```

4. GitHubのリポジトリ画面で「Settings」→「Pages」を開きます。
5. 「Build and deployment」のSourceを「Deploy from a branch」にします。
6. Branchを「main」、フォルダを「/(root)」にして「Save」を押します。
7. 数分後に表示される公開URLをiPhoneで開きます。

公開リポジトリにはアプリのコードだけが置かれます。登録した支出・残高・カード情報はGitHubへ送信されません。

## 4. iPhoneのホーム画面へ追加する

1. GitHub Pagesの公開URLをSafariで開きます。
2. Safari下部の共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. 名前を確認して「追加」を押します。

以後はホーム画面のアイコンからアプリのように開けます。

## 5. データをバックアップする

1. 下部の「設定」を開きます。
2. 「JSONで書き出す」を押します。
3. ダウンロードされたJSONファイルをiCloud Driveなどへ保存します。

戻すときは「JSONから読み込む」で同じファイルを選び、表示された件数を確認してから読み込みます。読み込むと、現在のデータはバックアップ内容へ置き換わります。

## 6. 知っておくこと

- データはlocalStorageに保存されます。ブラウザデータを削除すると失われることがあります。
- iPhoneとパソコンなど、別端末には自動同期されません。端末ごとにJSONの書き出し・読み込みが必要です。
- Safariのプライベートブラウズは保存用途に向きません。
- 祝日によるカード支払日の変更は自動計算しません。該当するカード支出の編集画面で支払日を手動変更できます。
- アプリ名を変える場合は、VS Codeの全体検索で「あといくら」を検索して置き換えます。
- 将来Supabaseを導入すると、ログイン、端末間同期、クラウドバックアップを追加できます。

## 7. 更新したのに古い画面が出る場合

まずページを再読み込みしてください。それでも変わらない場合は、`service-worker.js`先頭付近の`CACHE_VERSION`を`v1.0.1`のように変更してから再公開します。
